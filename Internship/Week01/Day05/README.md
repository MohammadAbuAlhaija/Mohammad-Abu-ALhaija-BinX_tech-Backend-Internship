## 📅 Week 1 — Day 5:Git & GitHub Workflow + Week 1 Wrap-Up

On this day, I learned Git fundamentals and applied a professional workflow to the project:

- Used the core Git loop: `git add` → `git commit` → `git push`.
- Worked on a **feature branch** instead of committing directly to `main`, to keep `main` stable and deployable.
- Wrote clear, specific commit messages in imperative mood (e.g. `Add domain model with User and Order classes`).
- Opened a **Pull Request** from the feature branch into `main` with a description explaining the changes.
- Prepared a Week 1 summary (environment setup, C# exercises, OOP, LINQ, async) as the week's final documentation.

**Tools Used:** Git • GitHub • Notion

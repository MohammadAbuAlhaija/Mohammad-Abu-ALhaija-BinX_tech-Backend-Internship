# BinX Tech — Backend .NET Internship Journey

This repository documents my progress through **BinX Tech's Backend Development Internship** — a structured, 400-hour program focused on building production-grade REST APIs with C# and ASP.NET Core.

## About the Program

- **Duration:** 400 hours across 10 weeks (full-time)
- **Track:** Backend Development — .NET & C# / ASP.NET Core
- **Format:** Guided technical training + hands-on project work under mentor supervision

The program takes participants from core programming fundamentals to designing, building, testing, and deploying a full production-grade REST API.

## Program Phases

| Phase | Focus |
|-------|-------|
| **Phase 1 — Foundations** | C# fundamentals, .NET SDK setup, Git, CLI basics |
| **Phase 2 — Core Technical Training** | ASP.NET Core, Entity Framework Core, SQL Server, authentication, testing |
| **Phase 3 — Applied Project Work** | Full REST API project built in Agile sprints, with live deployment |
| **Phase 4 — Final Evaluation** | Final presentation, feedback, and certification |

## Tech Stack

- **Language & Framework:** C#, .NET, ASP.NET Core
- **Database:** SQL Server / PostgreSQL, Entity Framework Core
- **Auth:** JWT, ASP.NET Core Identity
- **Testing:** xUnit, Moq
- **DevOps:** Docker, GitHub Actions (CI/CD), Azure App Service / Railway

## Repo Structure

Progress is documented week by week, with each week covering its own set of topics, labs, and concepts as the program moves from fundamentals toward a full applied project.

## Goal

By the end of the program, this repo will include a fully documented, tested, and deployed REST API — built end-to-end as the capstone project for Phase 3.
